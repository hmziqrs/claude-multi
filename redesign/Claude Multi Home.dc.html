Quick start

Two steps.
No flags to remember.

01

Launch the TUI

Type claude-multi and hit enter. The menu adds an instance, picks a provider, takes the key, and asks what to copy from the default Claude setup.

02

Run the new alias

The wizard prints something like claude-glm. Run it. Every flag and slash command from claude works as expected.

The whole flow lives in the menu. No subcommands, nothing to memorize.
